```text
DeployAlign 0.4 — Evidence-Gated Decision Compiler for Robotics Deployment (Demo)
```

**Description**

```text
DeployAlign compiles scattered deployment promises — a customer note, a sales proposal and an engineering review — into a typed commitment graph, deterministic diagnostics with exact source quotes, the smallest evidence-supported scope patch, and audience-specific documents that share one decision ID. Gemini may propose quote-grounded candidates; deterministic TypeScript rules decide; a person approves.

This is a SYNTHETIC demonstration: a fictional sub-fab Raman inspection pilot (the Korean brief in the second half is the same fixture translated). No customer data, revenue, production deployment or measured field outcome is shown or claimed. The recording runs the deterministic path; the public demo additionally runs Gemini 3.7 Flash through Vertex AI (live-verified 2026-08-26).

New since the first video: execution-origin labelling (0.2), paste your own three documents locally with English or first-pass Korean detectors and Markdown/JSON export (0.3), and a CLI — `deployalign compile … --fail-on blocker` — that fails a docs pipeline with exit code 2 when a proposal outruns its evidence (0.4).
```
