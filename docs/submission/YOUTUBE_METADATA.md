**Description**

```text
DeployAlign compiles scattered deployment promises — a customer note, a sales proposal and an engineering review — into a typed commitment graph, deterministic diagnostics with exact source quotes, the smallest evidence-supported scope patch, and audience-specific documents that share one decision ID. Gemini may propose quote-grounded candidates; deterministic TypeScript rules decide; a person approves.

This is a SYNTHETIC demonstration: a fictional sub-fab Raman inspection pilot. No customer data, revenue, production deployment or measured field outcome is shown or claimed. The recording runs the deterministic path (badge: "Deterministic fixture fallback · API"); the public demo additionally runs Gemini through Vertex AI.

New in 0.2.0: every result is labelled with its execution origin (API vs in-browser), the default model moved to Gemini 3.7 Flash, API contract tests and CI were added, and the docs are available in English, Korean and Chinese.
```
